# gemini-exporter

Android-приложение, которое сохраняет чат из Gemini в **PDF** или **Markdown** —
с вашими сообщениями, ответами Gemini и картинками.

## Установка

1. Откройте [последний релиз](https://github.com/Hpjgyfryfuj/gemini-exporter/releases/latest)
   и скачайте `gemini-exporter.apk`.
2. Откройте файл на телефоне и разрешите установку из этого источника, если Android спросит.

Нужен Android 10 или новее.

## Как пользоваться

1. Откройте чат в приложении Gemini.
2. Нажмите «Поделиться» (в меню ⋮ чата или под ответом) и создайте публичную ссылку.
3. В списке приложений выберите **Gemini Exporter**.
4. Когда чат загрузится, нажмите **Скачать PDF** или **Скачать Markdown**.

Ссылку вида `g.co/gemini/share/…` можно и вставить вручную в поле вверху.

Файлы сохраняются в `Загрузки/Gemini Exporter`. Markdown с картинками сохраняется
папкой: файл `.md` и рядом подпапка `images`.

## Как это работает

Приложение открывает публичную страницу чата (вход в Google не нужен), находит на ней
сообщения и картинки и собирает из них документ. Если Google изменит вёрстку страницы и
сообщения перестанут распознаваться, приложение сохранит страницу целиком.

PDF сохраняется сразу в «Загрузки». Если телефон этого не позволяет, откроется системное
окно печати — там нужно выбрать «Сохранить как PDF».

## Сборка

APK собирает GitHub Actions (`.github/workflows/build.yml`) при каждом push и выкладывает
его в Releases. Локально: `./gradlew assembleRelease` (нужен Android SDK).

Ключ подписи `app/release.jks` лежит в репозитории, чтобы каждая сборка ставилась поверх
предыдущей. Приложение не хранит никаких данных, поэтому ключ ничего не защищает.
